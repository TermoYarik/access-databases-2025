# Access-Datenbanken – Praktikum 2025

Zwei Datenbanken, die ich 2025 im Praktikum mit Microsoft Access erstellt habe.
Zum Öffnen wird Microsoft Access benötigt.

## KeyManagement.accdb – Schlüsselverwaltung

Datenbank für ein Gebäude: Welche Schlüssel öffnen welche Türen und wer hat welchen Schlüssel.
Tabellen: Personen, Schlüssel, Türen, Schliessgruppen, Schlüsselausgabe.
Mit Formularen, Abfragen (z. B. welche Türen eine Person öffnen kann) und Berichten.

## DiscordServers.accdb – Server im Discord-Stil

Modell eines Messengers: Server, Kanäle, Benutzer, Rollen und Nachrichten.
Mit Formularen, Abfragen (alle Nachrichten, Anzahl der Rollen pro Benutzer, Rollen eines Benutzers auf einem Server) und Berichten.
